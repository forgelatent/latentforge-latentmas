**Q1.**

* **Is the implementation correct?** **Yes**, the written-out formula in [E4] faithfully implements [E2] Step 5 ("The primary endpoint is recomputed with the same per-group weights and the same group means, resampling sensitivity blocks instead of primary groups"). Specifically, if there are $B$ sensitivity blocks and each resample draws $B$ blocks with replacement (equal probability $1/B$ per block), and the resample's statistic is the ratio estimator $\hat{\theta}^* = \frac{\sum_{k=1}^B \sum_{g \in b^*_k} d_g}{\sum_{k=1}^B \vert{}b^*_k\vert{}}$ (where $\vert{}b^*_k\vert{}$ is the number of primary groups inside drawn block $b^*_k$), each included primary group receives weight 1 per draw of its block and the original sample point estimate is identical to the primary point estimate $\bar{d}_g = \frac{1}{G}\sum_{g=1}^G d_g$ [E2, E4].
* **How the point estimate could lawfully differ (or be biased in the bootstrap distribution):** Because sensitivity blocks contain unequal numbers of primary groups $\vert{}b\vert{}$, the denominator $\sum_{k=1}^B \vert{}b^*_k\vert{}$ varies across bootstrap resamples, making $\hat{\theta}^*$ a **ratio estimator** (ratio of two random variables). While the plug-in point estimate on the original sample equals $\bar{d}_g$, the **mean of the bootstrap distribution** $E^*[\hat{\theta}^*]$ does *not* equal $\bar{d}_g$ whenever block size $\vert{}b\vert{}$ correlates with mean group performance $d_g$ inside the block ($O(1/B)$ ratio bias, which is non-negligible if $B$ is small) [E3, E4]. Furthermore, if the code mistakenly divides by the fixed total $G$ instead of the resample's actual group count $\sum_{k=1}^B \vert{}b^*_k\vert{}$, the bootstrap variance will be artificially inflated by random sample-size fluctuations even when $d_g$ is constant across all groups.
* **How it overstates or understates uncertainty:**
* *Overstates uncertainty (when $B$ is small or one block is huge):* If the connected components of shared drivers collapse a large share of the $\ge 150$ primary groups into a few mega-blocks [E3], the effective number of clusters $B_{\text{eff}} = (\sum \vert{}b\vert{})^2 / \sum \vert{}b\vert{}^2$ drops sharply. Standard percentile bootstrap confidence intervals on cluster-robust ratio estimators with few or highly unbalanced clusters have poor coverage and erratic tails [E3, E4].
* *Understates uncertainty (if a shock hits `none` singletons):* Events tagged `none` remain single-group sensitivity blocks [E2, E3], so any unmodeled shared driver omitted from [E3] is treated as independent across resamples.

* **What "sensitivity interval > 0" allows a run to claim:** It allows a run to claim that (1) under the primary independence definition [E1, E2], latent beats text by more than the practical margin $m$ with 95% confidence, AND (2) even under extreme macro-shock clustering [E3], the positive superiority of latent over text is not a zero-effect noise artifact ($\text{LB}_{\text{sens}} > 0$).



**Q3.**

* **Must both gates survive sensitivity resampling?** **Gate 1 (pairing: $\text{Brier}_D - \text{Brier}_L > 0$) MUST survive sensitivity resampling (interval > 0); Gate 2 (usefulness: $\text{Brier}_S - \text{Brier}_L > 0$) does NOT need a separate sensitivity gate if the primary endpoint ($L$ vs $T$) already survives sensitivity.**
* **Failure shapes permitted by each choice:**
* **Gate 1 (the channel carries task-relevant content [E4]):**
* *If required to survive sensitivity:* Prevents a **domain-shock/base-rate artifact** where $D$ (drawn from another block) degrades performance only on one large macro block (e.g., D01 US–Iran or D03 Russia–Ukraine [E3]) where base rates or probabilities were extreme, making $\text{Brier}_D - \text{Brier}_L$ look significant across 30 correlated primary groups when it was really a single geopolitical shock. * *If NOT required to survive sensitivity:* Permits a run where $L$ beats $D$ only inside a single heavily sliced geopolitical shock block [E3] to pass Gate 1 by counting the slices' primary groups as independent confirmations of content transfer.


* **Gate 2 (the channel beats silence / single agent $S$ [E4]):**
* *If required to survive sensitivity:* Permits a **false FAIL from baseline variance inflation**. Agent $S$ (no message) and Agent $T$ (text draft) use the exact same checkpoint and input [E4]; unless text communication $T$ is actively worse than silence $S$ ($\text{Brier}_T > \text{Brier}_S$), $L$ beating $T$ by $> m$ already implies $L$ beats $S$. Adding a separate sensitivity-interval hurdle on $\text{Brier}_S - \text{Brier}_L$ adds a redundant statistical penalty where block-level variance in single-agent baseline skill can trigger a FAIL even when $L$ beats $T$ under sensitivity and $L$ beats $S$ under primary groups.
* *If NOT required to survive sensitivity:* Only permits a dubious PASS if **text $T$ actively harmed Agent B relative to silence $S$** within a specific macro block, so that $L$ beat $T$ under sensitivity solely because $T$ failed, while $L$'s edge over $S$ was confined to a single correlated shock. (That edge case is easily closed by requiring the point estimate $\text{mean}(\text{Brier}_S - \text{Brier}_T) \ge 0$ or keeping Gate 2 at the primary group level.)

Instead of matching on raw character/token length, **truncate or pad all drafts (or fix max generation tokens in the budget rule)**, or match donors by **stratum of single-agent probability $p_S$ (or market base-rate stratum)** so donor and recipient have uncorrelated length conditioned on difficulty.
* **What else must the rule fix so $D$ is a control and not a second experiment [E6]:**
1. **Strict bijection / one-to-one derangement without replacement (or bounded donor reuse):** If the seeded deterministic rule [E4] picks the single closest length match from another sensitivity block *with replacement*, a handful of idiosyncratic "canonical length" drafts could be injected as the donor across dozens of target markets—turning $D$ into an experiment on those few donor drafts [E6]. **Q6.**

* **Is $\delta = 0.10$ the right line, or should it be dropped?** **Keep the secondary endpoint as descriptive only, OR replace fixed $\delta = 0.10$ with a scale-aware threshold (specifically log-odds difference $\vert{}\text{logit}(p_L) - \text{logit}(p_T)\vert{} \ge \delta_{\text{logit}}$ or scaled by $\sqrt{\bar{p}(1-\bar{p})}$), because a flat $\delta = 0.10$ is distorted by the 80.2% NO base rate [E4].**
* **Why flat $\delta = 0.10$ fails on this pool:** In a pool where 329 of 410 markets resolve NO (19.8% YES rate) and many markets are mutually exclusive slices [E3, E4], most well-calibrated probabilities sit near the boundaries (e.g., $0.02$ to $0.15$). A shift from $p_T = 0.02$ to $p_L = 0.11$ is a $5.5\times$ change in odds, yet fails $\delta = 0.10$ ($\vert{}0.11 - 0.02\vert{} = 0.09 < 0.10$), whereas a shift from $0.45$ to $0.55$ near maximum uncertainty is a tiny informational update that passes $\delta = 0.10$. Scaling the threshold by baseline uncertainty—e.g., defining divergence as $\frac{\vert{}p_L - p_T\vert{}}{\sqrt{\bar{p}(1-\bar{p})}} \ge 0.25$ (where $\bar{p} = (p_L + p_T)/2$, which equals $0.125$ at $\bar{p}=0.50$ and $0.075$ at $\bar{p}=0.10$)—puts boundary markets and toss-up markets on the same statistical footing.
* **What makes it falsifiable rather than descriptive:** Because the set of markets satisfying $\vert{}p_L - p_T\vert{} \ge \delta$ is a **post-treatment conditioning set** (determined by the models' outputs, which can have size $N=0$ or $N=5$), a bootstrap interval conditioned on a post-treatment subset cannot be a formal pass/fail gate without risking post-selection bias or division by zero. To make it falsifiable, pre-register a directional test on the **full unconditional sample**: the covariance (or regression slope) between magnitude of divergence $\vert{}p_L - p_T\vert{}$ and paired Brier improvement $d_m = \text{Brier}_T(m) - \text{Brier}_L(m)$ across all groups must be positive ($\text{Cov}_g(\vert{}p_L - p_T\vert{}, d_g) > 0$), testing whether larger latent-vs-text disagreements systematically produce larger accuracy gains without conditioning on an arbitrary cutoff $\delta$.
