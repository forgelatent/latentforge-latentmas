SUGGESTION 1
Technique: Predictive Coding Residual Transmission
Field: Computational Neuroscience / Hierarchical Predictive Processing
Core idea: Transmit only the *prediction error* between what the receiving agent expects and what the sending agent actually holds — mirroring how the mammalian cortex suppresses redundant signals by only passing surprise upward through layers.
Why LatentForge: The shared seed vector is already functioning as a prior. Rather than treating the delta as a raw difference from seed, structure the compression around a *learned expectation model* that each agent maintains about its partner's likely next state. The sender runs a lightweight forward model of "what will the receiver predict I'm holding?" and subtracts that from the actual latent — transmitting only the residual of the residual. This double-difference scheme can dramatically reduce the magnitude of transmitted components, making top-k sparsity cut harder without losing divergence signal. The key insight from predictive coding is that *surprise is information-dense and low-volume* — the cortex achieves something like 10:1 compression purely through hierarchical prediction suppression before any other encoding. For LatentForge, this means the k=128 budget is spent almost entirely on genuinely novel signal rather than on slowly-drifting components that both agents could have predicted.
Test in one week: Using Claude API, run two agents on a shared task (e.g., collaborative story generation across 10 turns). Agent A maintains a rolling exponential moving average (α=0.3) of Agent B's last 5 latent deltas as a "prediction." Before applying top-k, subtract this prediction from the new delta, transmit the residual, and have Agent B reconstruct by adding its own matching EMA back. Measure: does divergence-from-seed correlation hold better at the same k vs. raw delta transmission? Implement entirely in NumPy on MacBook.

SUGGESTION 2
Technique: Genomic Linkage Disequilibrium Pruning for Correlated Dimension Suppression
Field: Population Genomics / Statistical Genetics
Core idea: In genome-wide association studies, LD pruning removes SNPs that are highly correlated with already-selected SNPs to find a maximally *informative, non-redundant* subset — apply this to latent dimensions to select k indices that are maximally decorrelated rather than simply top-magnitude.
Why LatentForge: Current top-k selects the 128 highest-magnitude components, but high-magnitude dimensions in a transformer latent space are often *co-linear* — they move together because they encode related semantic features. This is the latent-space analogue of linkage disequilibrium: you're spending k-budget on correlated dimensions that carry overlapping information. LD pruning's algorithm works by iteratively selecting a candidate dimension, then suppressing all other dimensions whose pairwise correlation exceeds threshold r²>0.2 (standard in genomics), then selecting the next highest-magnitude from the remaining pool. Applied to LatentForge: precompute a correlation matrix across dimensions from a calibration run, then at transmission time use greedy LD-style pruning to select k dimensions that are both high-magnitude *and* mutually decorrelated. This is strictly more information-efficient than top-k magnitude alone and is injective within a definable domain. No neural network required — it's a fast greedy set selection algorithm.
Test in one week: On MacBook, collect 50 latent delta vectors from Claude API responses (same prompt family). Compute 1536×1536 (or whatever Claude's embedding dim exposes) pairwise Pearson correlation matrix. Implement greedy LD pruning: sort dims by magnitude, greedily add dims with |r|<0.3 to all previously selected. Compare: for same k=128 budget, does LD-pruned selection reconstruct more of the original vector's explained variance than top-k magnitude? Use cosine similarity to ground truth as metric. Numpy + scipy only.

SUGGESTION 3
Technique: Topological Persistent Homology Landmarks as Stable Compression Anchors
Field: Algebraic Topology / Topological Data Analysis
Core idea: Persistent homology identifies which features of a high-dimensional point cloud are *topologically stable* across scale — use homological persistence as a criterion for which latent dimensions to treat as structural anchors that should never be dropped by sparsity.
Why LatentForge: The Shadow Self drift-monitoring problem is fundamentally a question of *which dimensions encode structural identity vs. transient content*. TDA's persistence diagram gives exactly this: dimensions (or small clusters of dimensions) with high persistence are those whose information survives across multiple scales of the latent manifold — they're the "load-bearing walls" of the agent's representational structure. A compression scheme that protects high-persistence dimensions from top-k pruning, even when their magnitude is low, would preserve the manifold geometry that governs agent divergence. Concretely: run a Vietoris-Rips filtration on a corpus of latent vectors to identify which *individual dimensions* contribute most to persistent 0-cycles and 1-cycles. Flag these as protected indices. At compression time, always include protected indices in the k budget, using remaining slots for top-k magnitude selection among unprotected dims. This gives compression that is geometrically faithful, not just magnitude-faithful — a property that current latent agent communication work completely ignores.

Metric: variance of the agent's cosine similarity to shared seed across turns.
